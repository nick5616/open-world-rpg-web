# Cost notes (stub for WP19)

Spec 13 rule 6: *a small dashboard tracks monthly cost divided by peak
concurrent players, and WP19 records it in `docs/decisions/v1-capacity.md`.*

- **Dashboard:** Grafana "Lodestone cost per player"
  (`infra/observability/grafana/dashboards/lodestone-cost.json`, generated by
  `gen-dashboards.mjs`). Type the month's bill into the `monthly_cost_usd`
  box; peak CCU is `max_over_time(sum(zone_players)[30d])`; the tile divides.
- **Where the bill comes from:** Cloud Console > Billing > Reports, filter the
  project, group by SKU. Netlify: team > Billing (free tier unless bandwidth
  runs over).

## What the deployment costs when nobody plays (list prices, us-central1, Nov 2026, to be checked by WP19)

| Item | Idle | Per awake hour / per use | Notes |
| --- | --- | --- | --- |
| Game VM e2-standard-2 | 0 (stopped) | ~$0.067/h | Billed only while awake (wake on demand). |
| VM boot disk 20 GB pd-balanced | ~$2.00/mo | | Persists while stopped. |
| Data disk 20 GB pd-balanced | ~$2.00/mo | | Postgres, Redis AOF, Caddy certs, images. |
| Static external IPv4 | ~$7.30/mo while the VM is stopped | ~$0.005/h while running | The largest idle line. An ephemeral IP would remove it but changes the game host on every wake (decision 0018). |
| Cloud Run director/account/creator | ~0 | per request | Min instances 0; the 5-minute scheduler ping costs cents. |
| Cloud Scheduler | 0 | | 3 free jobs per billing account; we use 1. |
| Secret Manager | ~$0.06/secret/mo -> ~$0.85/mo | | 14 secrets; access calls are within the free tier at this volume. |
| Artifact Registry | ~$0.10/GB/mo | | ~5 images x a few versions; prune old tags if it grows. |
| Cloud Storage | cents | | Dumps (60-day lifecycle) + worldgen wasm (~350 KB per version, kept forever). |
| Egress | 0 | ~$0.12/GB to the internet | The real cost (spec 13 rule 4): zone snapshots at <= 160 kbps/player ≈ 72 MB/player-hour ≈ $0.009/player-hour. Voice egress bounded by the 12-speaker earshot cap. |
| Netlify | 0 | | Free tier: 100 GB/mo bandwidth; hashed assets cache forever. |

Idle total, rough: **~$12/month**, dominated by the static IP and disks.
